# drafts — 예약 발행 창고

여기에 `week-02/`, `week-03/` 처럼 다음 주차 폴더를 미리 만들어 push 해두면,
매주 토요일 워크플로가 **번호가 가장 낮은 주차 하나**를 저장소 루트로 꺼내
정식 커밋한다.

## 사용법
1. 여유 있을 때 `drafts/week-02/` 폴더를 만들고 그 안에 PLANNING.md, 소스 등을 채운다.
2. `git add -A && git commit -m "draft: week-02 준비" && git push` (아직 창고 상태, 미공개)
3. 다가오는 토요일에 자동으로 `week-02/`가 루트로 옮겨지고 공개 커밋된다.

## 규칙
- 폴더명은 반드시 `week-XX` 형식(숫자 2자리 권장: week-02, week-10).
- 창고가 비어 있으면 그 주 토요일엔 아무 일도 일어나지 않는다(정상).
- 수동으로 지금 당장 하나 발행하고 싶으면 Actions 탭 → Run workflow.
