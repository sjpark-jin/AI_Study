1. 왜 단순 Vector 검색을 넘어 Hybrid + Reranker인가?

기존 Dense Vector 임베딩 검색은 자연어 질문의 문맥적 유사도를 찾는 데 뛰어나지만, 고유명사, 에러 코드(K8S-INGRESS-404), 모델명(GPU-A100-CUDA12), 법률/규정 조항(제14조)과 같은 정확 매칭이 필요한 도메인에서 치명적인 누락이 발생합니다. 반면 BM25는 키워드 정확 일치에 강하나 패러프레이징(말바꿔쓰기)을 이해하지 못합니다.
따라서 "BM25 + Dense Vector + RRF 융합 + Cross-Encoder Reranker"의 4단계 하이브리드 파이프라인이 최신 실무 RAG의 표준 아키텍처로 자리잡았습니다.

[사용자 질문] │ ├── 1. BM25 키워드 검색 ────────┐ (Okapi BM25 스코어) │ │ └── 2. Dense Vector 검색 ───────┼──> [3. RRF 순위 융합 (Top-K)] ──> [4. Cross-Encoder Reranker (Top-N)] ──> [LLM 답변 생성] │ │ └─────────────────────────────────── [5. Ragas 3대 지표 정량 평가] <────────────────┘ - Faithfulness (환각 여부) - Answer Relevance (답변 부합도) - Context Precision (상위 문서 적중률)

2. 만들어보며 겪은 10가지 실수 노트 (Troubleshooting Guide)

현업에서 하이브리드 RAG 및 평가 파이프라인을 구축할 때 가장 빈번하게 발생하는 함정과 극복 방법입니다.

# 문제 현상 왜 발생했나? (원인) 이렇게 해결함 (해결책)
1 에러코드 검색 시 엉뚱한 문서 반환 단일 Dense Vector 임베딩이 하이픈(-) 포함 특수 토큰을 제대로 인코딩하지 못함 BM25 키워드 검색기를 병행 배치하여 고유 에러코드 정확 매칭 우선권 부여
2 BM25와 Dense 점수의 직접 합산 왜곡 BM25 점수(0~15+)와 Dense 코사인 유사도(0~1)의 스케일 차이로 한쪽이 결과 독점 절대 점수가 아닌 순위 기반 RRF(Reciprocal Rank Fusion, k=60) 알고리즘 적용
3 Reranker 적용 시 속도 저하(Latency 급증) 전체 코퍼스 문서에 대해 무거운 Cross-Encoder를 실행함 1차 융합으로 상위 4~8개 후보군만 추린 후 소수 Top-K에 대해서만 Rerank 수행
4 Reranker가 오히려 질문 키워드를 무시 Cross-Encoder 입력 시 문서의 제목(Title) 메타데이터를 누락하고 본문만 전달 `[문서 제목] + \n + [문서 본문]` 형태로 문맥을 재구성하여 Reranker에 주입
5 RAG 답변에 문서에 없는 추측 포함 (Hallucination) 시스템 프롬프트에 "제공된 문서에만 기반할 것"이라는 제약 조건이 모호함 프롬프트 강화 및 Faithfulness 평가 지표를 연결하여 환각 발생 시 자동 재작성 유도
6 한국어 조사로 인한 BM25 매칭 실패 단순 공백 단위 분절 시 '에러코드는', '에러코드가'를 서로 다른 토큰으로 인식 한글 어절 및 특수문자 보존 복합어 정규식 토크나이저(`tokenize_text`) 구현
7 ChromaDB 최초 구동 시 지연 요청마다 임베딩 모델과 벡터스토어를 반복 생성함 싱글톤 패턴(`HybridRetriever`)으로 서버 기동 시 최초 1회만 적재되도록 캐싱
8 평가 결과 JSON 파싱 에러 LLM-as-a-Judge 응답에 서론/마크다운 블록이 섞여 `json.loads` 예외 발생 Pydantic 기반 정규식 정제 및 Fallback 기본 점수 방어 로직 구축
9 문서가 짧을 때 BM25 점수 과대평가 BM25 공식에서 문서 길이 정규화(b=0.75)가 짧은 문장에 지나친 패널티나 왜곡 유발 `avgdl` 분모 0 방지(max 1e-6) 및 최소 토큰 길이 보정
10 API 키 미설정 시 파이프라인 전체 다운 로컬 환경이나 테스트 시 외부 OpenAI 서버 연동 장애에 취약 MockLLMProvider를 탑재하여 키 없이도 전 구간 시뮬레이션 및 교육 검증 보장
