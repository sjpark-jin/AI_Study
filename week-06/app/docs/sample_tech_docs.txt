[문서 ID: DOC-INFRA-001]
제목: 사내 클라우드 Kubernetes 인그레스 장애 대응 및 에러 코드 K8S-INGRESS-404
내용:
사내 MSA 환경에서 클러스터 외부 인입 트래픽이 차단되거나 백엔드 서비스 파드(Pod)로 라우팅되지 않을 때 발생하는 주 에러 코드는 K8S-INGRESS-404입니다.
이 에러가 발생한 경우 인그레스 컨트롤러(Nginx Ingress Controller)의 서비스 라우팅 규칙 및 TLS 인증서 시크릿 바인딩을 확인해야 합니다.
조치 명령어: `kubectl describe ingress -n production`을 수행하여 Annotations 설정과 Service 백엔드 포트 포워딩 상태를 점검하십시오.
로그 수집 경로: `/var/log/nginx-ingress/access.log`

[문서 ID: DOC-AUTH-002]
제목: 차세대 인증 시스템 사양 (AUTH-JWT-V2 규격)
내용:
2026년 하반기부터 사내 모든 마이크로서비스에 적용되는 통합 인증 프로토콜은 AUTH-JWT-V2 규격을 준수해야 합니다.
토큰 만료 시간은 Access Token 기준 15분, Refresh Token 기준 7일입니다.
서명 알고리즘은 RS256을 사용하며 비대칭 암호화 키 페어(RSA 4096-bit)로 서명됩니다.
외부 게이트웨이 통과 시 헤더 `X-Enterprise-Auth-Token`에 전달되어야 하며, 권한 위임 플래그가 포함되어야 합니다.

[문서 ID: DOC-DB-003]
제목: 데이터베이스 커넥션 풀 고갈 및 타임아웃 장애 (DB-CONN-TIMEOUT-1002)
내용:
트래픽 급증 또는 장기 실행 쿼리로 인해 커넥션 풀이 고갈될 때 DB-CONN-TIMEOUT-1002 경고가 발생합니다.
HikariCP 기준으로 기본 maximumPoolSize는 30으로 권장되며, connectionTimeout은 3000ms입니다.
해당 에러 발생 시 슬로우 쿼리 로그(Slow Query Log)를 분석하여 N+1 쿼리 또는 인덱스 누락 여부를 프로파일링해야 합니다.

[문서 ID: DOC-POLICY-004]
제목: 하이브리드 원격 근무 및 사내망 보안 접속 가이드
내용:
원격 근무 시 모든 임직원은 사내 보안 VPN(Cisco AnyConnect / WireGuard Enterprise)을 통해 접속해야 합니다.
개인 디바이스로 사내 소스코드나 데이터베이스 덤프를 로컬 디스크에 직접 저장하는 것은 정보보안 규정 제14조에 의해 엄격히 금지됩니다.
외부 네트워크 접속 시 2단계 인증(OTP/FIDO2)을 거쳐야 하며, 3회 이상 인증 실패 시 계정이 자동 잠금 처리됩니다.

[문서 ID: DOC-AI-005]
제목: 대형 언어 모델(LLM) 서빙 인프라 GPU-A100-CUDA12 최적화 규격
내용:
사내 생성형 AI 파이프라인 서빙을 위한 GPU 인프라 표준 사양은 NVIDIA A100 80GB SXM 기반의 GPU-A100-CUDA12 환경입니다.
vLLM 및 TensorRT-LLM 엔진을 컨테이너로 기동하며, PagedAttention과 FP8/BF16 양자화를 기본 적용합니다.
최대 동시 요청(Concurrent Requests)은 인스턴스당 64개로 제한하며, 요청 지연 시간(TTFT) 200ms 이내 유지를 목표로 합니다.
